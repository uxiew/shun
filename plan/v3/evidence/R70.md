注入多点触摸要带 `ABS_MT_PRESSURE` 和 `ABS_MT_TOOL_TYPE`：不带压力 Android 当成悬停，App 收不到触摸；不带工具类型 Flutter 报 `unknown`，`adb input` 的手指也报 `unknown`，只收 `touch` 的识别器看不到它。比「终端不滚」要先滚进历史：手指往上是往新的方向滚，停在最底下时本来就滚不动，比了也白比。

## 跑真设备才抓到的

下面这些单测一开始都是过的，每条都补了测试。总览重连、大输入框菜单这两条确认过：改回旧写法，测试会失败。

- **点完重连接着切过去，指纹、密码框被直接拒绝。** 问答挂在总览自己的 context 上，总览收了就按拒绝处理，连接莫名失败；「全部重连」也停在半途。现在挂在 Navigator 那一层。
- **键盘弹着时够不到总览。** 底栏被键盘盖住，手指滑在键盘上 App 收不到；全屏没有底栏。加了「更多 → 会话总览」。
- **键盘会弹回来盖住总览。** 菜单一关焦点还给终端，只 unfocus 一次拦不住。现在总览开着时下面的页拿不到焦点。
- **键盘弹着时「更多」里每一项都没反应（早就有的 bug）。** 菜单抢焦点 → 键盘收起 → 快捷栏换摆法 → 按钮被卸载 → `onSelected` 不再回调。大输入框一行摆法的「…」一样，点「清空」字还在。都改成菜单项自己的 `onTap`。
- **切到第四个标签后，标签条不动，当前标签看不见。** 现在滚过去。不用 GlobalKey：拖动标签时列表会把同一项再建一遍当拖影，会重复。

## 最后一轮走查抓到、已修的

加了真实进出画中画（`75b1202`）才看到，修前修后对比截图：`r70-device-20261101-133233/` 和 `r70-device-20261101-153004/` 里的 `40-picture-in-picture.png`、`41-back-from-picture-in-picture.png`。

- **点过终端再进画中画，小窗是空的，回全屏也没回来（`f9824b9`）。** 字没丢，全被挤进了回滚区。点一下终端，Ghostty 的选字手势留一个跟踪锚点判断双击（`left_click_pin`），点完不释放；窗口变矮时裁尾部空行碰到锚点就停，45 行缩到 3 行时只裁到点过的那一行，可视区剩下的全是空行。放大也拉不回来：先拉回来的是挨着可视区的那些空行，文字还在它们上面。没点过就不出这个问题，所以以前没撞上。现在 flterm 在行数变少之前先放掉这个锚点。原来猜的「行数一度很小」不对：逐帧记录看到是从 45 行直接到 3 行。
- **从画中画、全屏回来，标签条退回第一个标签（`3152dcf`）。** 标签条是新建的，偏移归零，当前标签又没变，所以不跟。现在标签条一出现就滚到当前标签。全屏回来测试也红过，确实一样。

修复后：画中画里看到 `l -f app.log | GET /health 200`（3 行放不下时第一行露后半截，正常），回全屏两行字都在，当前标签在标签条里。

- 真 shell 上没跑。原因在引擎，和会话是不是塞进去的无关，但真连接上 shell 收到新尺寸后还会自己重画，这一段没看过。
