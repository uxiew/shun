## 做成了什么样

- **类型图标**：锁 = SSH、信号 = Mosh、线缆 = Telnet、拼图 = 插件，网格 / 列表 / 树形三种视图和 Tailscale 分节都有，读屏念「SSH 连接」这样的整句。角标是主机**保存的**默认方式。
- **⋮ 菜单**（点 ⋮ 或长按），打开那一刻算，用不了的不出现（不是变灰）：
  - 「用 Mosh / SSH 连接」：和终端里 R42 的「另开一个」同一套判断（直连、Mosh 选项合法、插件现在能用）；Mosh 主机总能用 SSH。另开标签、不改保存的默认方式、不跑启动命令。点的那一刻再查一遍，换不了就报原因、不连。
  - 「端口转发」「文件」「性能监控」：这台主机有**连着的 SSH 标签**才出现，用那条 SSH，不替用户先去连。认的是来源主机：Mosh 标签、断开的、别的主机的标签都不算。
  - 「测试连接」（范围里的「诊断」）：和编辑器一样只有普通 SSH、路线算得出来才有。每主机事件记录（UX10）归 R25，这次没做。
  - 「编辑」「在列表里隐藏 / 取消隐藏」：每台都有。
- **隐藏**存在主机的 `shunHidden` 字段，只管列表显示；照常能连、能当跳板、跟着保险库同步（桌面端不认识、照常显示）。底部「显示已隐藏的主机：N」找回来，刚藏时提示条上有撤销。
- **Tailscale 分节**：本机每个目录来源一组（按名字排），组头写「状态截至：时间 · 多久前」、最近一次读取失败的时间、没存凭据的提示，右边刷新和来源设置。
  - 绑定到本机来源的主机（导入的、手动关联的）从普通列表移进对应的组，显示用户起的名字、按主机列表的规则排（置顶优先、再按名字），点了、⋮ 和普通主机一样。来源不在本机的主机留在普通列表。
  - 没导入的设备点了打开导入页（只导这一台），不连接。
  - 状态写「Tailscale 控制面：已连接 / 未连接 / 不知道」或「目录：最近完整列表里没有它 / 缓存里没有这台设备」，只用字、不用绿点；节头一句说清「不代表手机能连上它，也不代表 SSH 开着」。
  - **只有点刷新才发请求**：打开列表、回到首页、下拉、从来源页回来都只重读本机缓存文件。一个来源同时只刷一次（刷着时按钮换成转圈）。没存凭据的来源点刷新打开来源页。刷新本身仍是 R12 的 `CatalogRefresher`，一行没改。
- **「切换来源」的取舍**：没做一次只显示一个来源的切换器，所有来源并排成组、点组头收起 / 展开。原因：绑定到来源的主机已经从普通列表移走，如果一次只显示一个来源，另一个来源的主机就哪里都找不到。收起 / 展开只改显示：不加入 tailnet、不碰任何 SSH 会话，下面实测过。所有者想要切换器的话再加。
- 选了自定义分组时不分节（目录设备不属于任何分组），那一组的主机都在普通列表；搜索时只留命中的设备和主机。

## 验收逐条

| 验收 | 结果 |
|---|---|
| 控制面状态和缓存时间独立于 SSH 连接状态；不用在线徽标，不把目录可见说成能连上 | 通过。设备上控制面「未连接」时 SSH 标签仍连着、两边各说各的；只用字，节头写明不代表能连上 |
| 没导入的目录设备点了走导入，不直接连 | 通过。设备和单测都是打开导入页、标签 0 个 |
| 菜单里不出现这台主机用不了的动作 | 通过。没连着没有转发 / 文件 / 监控，没插件没有 Mosh，Telnet 只有编辑和隐藏，同 IP 的另一台不借用别人的 SSH；出现的项在设备上都点通了 |
| 两来源同名或同 IP 的设备不合并、不互用身份；刷新不覆盖别名、用户名、端口、路线和指纹，删除来源不终止其他会话 | 通过。同名同 IP 同设备 ID 是两台主机、两个用户名；刷新后别名、用户名、端口、密码没变。路线和指纹：刷新对主机能做的改动只有地址和目录绑定两个字段（`CatalogHostChange`，类型上就改不到别的），已有指纹存在保险库 `knownHosts` 里、不在主机上，R12 的 TSC04 测试照样过；单测里另一来源、改过地址的主机整条字段不变。移除来源连它自己主机的会话都没断 |

停止条件「不为了显示在线状态在后台频繁刷新目录」：没有定时器、没有后台刷新，设备上只有点刷新那一下发了请求（见上）。

## 没验的

- **装着 Mosh 插件时的「用 Mosh 连接」**：模拟器上没装插件，只验了「没插件就不出现」。出现、点了另开 Mosh 标签、Mosh 主机的「用 SSH 连接」只有 `connection_switch_test` 里的控制器测试（插件是假的，编排是真的）。判断和 R42 终端菜单是同一个函数，R42 在模拟器上用真插件验过那一侧。
- 缓存旧了（「3 天前」）、最近一次读取失败、「最近完整列表里没有它」「缓存里没有这台设备」只有 widget 测试；设备上两个来源都是「刚刚」读的。
- 刷新时「按钮换转圈、不能再点」只在 widget 测试里用卡住的响应验过；设备上假 API 回得太快，点下后 30 ms 看，第一轮是转圈、第二轮已经刷完，没当断言。
- 真实 Tailscale、真机、API 35、iOS、英文界面在设备上的样子、树形视图在设备上的样子（设备上看到了网格和分节，树形和列表只有 widget 测试）。

## 留给后面的

- 要不要「一次只看一个来源」的切换器：现在是并排成组 + 收起，理由见上。所有者想要就再加，只切显示的规矩不变。
- 隐藏的主机在跳板机选择、关联到已有主机这些列表里照常出现（有意的：隐藏只管主列表）。
- 主列表不显示哪台主机现在有连着的标签，所以「为什么这台有端口转发、那台没有」只能靠手册解释。要不要加一个「已连接」标记，可以和 R25 的诊断入口一起定。
