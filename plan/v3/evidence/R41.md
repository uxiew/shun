## 和任务描述不一样的地方

- 任务里写「建议先用 SSH，连上后能切 Mosh」。实际写「建议先用 SSH 确认能连上，再改成 Mosh。」：在终端里切换是 R42，还没做，不能先许诺。R42 做完再改回。
- 「普通 SSH / Tailscale SSH 和认证方式并成一排」做成了一个下拉「认证方式」：自动 / 密码 / 私钥 / Tailscale SSH。选 Tailscale 时原 authMethod 和密码留着。
- 高级里的 tmux 组**只有说明，不存会话名**。docs/20 写明「不按名字自动附着」：tmux 的 `-t 名字` 先前缀匹配，`work` 没了会命中 `workshop`。选会话仍在终端的「系统管理 → tmux」按 R21 完整目标做；把选会话放进标签条是 R42 的范围。UX07 里「分别选择普通 shell 与指定 tmux 会话」按这个分工验：编辑页按 SSH / Mosh 分别说明，选会话的行为沿用已 PASS 的 TMX04/TMX05。
- 测试连接新增的 tmux 查询只看默认 socket；`-L`/`-S` 的在面板里换 socket 看。
