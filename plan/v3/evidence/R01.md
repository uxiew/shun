## 继承能力清单

| 入口 | 上游行为 | 本 fork 处理 |
|---|---|---|
| 检查更新 | **冷启动就请求** `api.github.com/repos/kmh1145/Netcatty-mobile/releases/latest`（设置页在 IndexedStack 里，启动即构建）。未经同意，且指向上游发布页（另一个 applicationId） | `ForkFeatures.updateCheck=false`，不创建服务、不发请求 |
| Catty Agent（AI） | 终端工具栏按钮 + 设置页服务商管理；只在用户操作时请求用户自配的 OpenAI 兼容地址 | `ForkFeatures.ai=false`，两个入口隐藏 |
| 云同步（WebDAV / GitHub Gist / S3） | 自动同步默认关；用户配置后启动、回前台、每 5 分钟同步 | `ForkFeatures.cloudSync=false`，设置区隐藏；本地残留 `autoSyncEnabled=true` 也不启动 |
| Telnet | 明文协议，**忽略代理配置直连** | 保留；配了代理时拒绝连接（R03） |

| `ssh://` deep link | Manifest 注册了（带无意义的 autoVerify），Dart/Kotlin 都没处理，点了只打开首页 | 保留，记录；不会自动连接 |
| 端口转发、SFTP、片段 | 用户触发 | 保留 |

**BAS02 怎么测**：不看代码、不打桩，看 Android 内核按 UID 记的流量。`adb shell dumpsys netstats --poll` 强制刷新后，
`dumpsys netstats detail` 里形如 `] uid=<App 的 uid> set=…` 的行就是这个 App 的流量记录；DNS 查询也记在发起 App 名下（tag `0xffffff82`）。

| 步骤 | 原版 uid 10214 | fork uid 10215 |
|---|---|---|
| 冷启动，等 12 秒 | **2 行**：收 7880 / 发 1225 字节，另有 DNS 收 196 / 发 180 字节 | — |
| 冷启动 → 设置页滑到底（懒加载项全部构建）→ HOME 8 秒 → 回前台 → 发 `ssh://nobody@192.0.2.1:22` deep link | — | **0 行** |

fork 设置页滑到底，可见项里没有云同步、Catty Agent、检查更新。deep link 能把 App 拉到前台，但 Dart/Kotlin 都没处理它（与上面继承清单一致），不会发起连接。
顺带发现：首页空状态文案仍写"云同步后也会出现在这里"，功能已关，文案没跟上（不影响网络，留给 UI 任务）。

**BAS03 怎么测**：原版里加一台测试主机（`bas03-test`，`tester@192.0.2.10:22`，192.0.2.x 是文档保留地址，填了一个假密码），
然后用 root 对 `/data/data/app.netcatty.mobile` 下除 cache 外的所有文件算 sha256 汇总：卸 fork → 算 → 装 fork 并启动 8 秒 → 再算。

|---|---|
| 原版数据 hash 前 / 后 | `b5f35f9b020644cb` / `b5f35f9b020644cb`，一致（8 个文件） |
