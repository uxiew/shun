## 2. 迁移边界与做法

FlClash 的编辑页是 iOS 式「标题 … 行内输入」（`FormRow` + `FormRowTextField`）。R84 已定输入框不换 Prism：Prism 的输入框没有浮动标签，shun 的表单和 FormGap 20dp 都按浮动标签定。所以本批**输入框（地址、端口、用户名、密码、名称、Mosh 参数、超时、标签、插件下拉、添加跳板机下拉）保持 Material**，类型、认证两行分段 R84 已是 ChoiceSegments；换的是表单里其余的表面：

| 部位 | 迁移前 | 迁移后 |
|---|---|---|
| 「高级」开关 | InkWell + 文字（能点，读屏不是按钮） | 单行 Prism 分组卡片（`ShunListRow`），读屏是带「已展开 / 已收起」的按钮，key `advanced-all`、`advanced-all-state` 不变 |
| 高级里各块小标题 | HintTitle（labelLarge） | Prism headline 字阶、次要文字色（和设置页小标题同一档），读屏是标题；没用 Prism ListHeader，它按卡片内容左缩 16dp，和贴页边的输入框错开 |
| 置顶显示 | SwitchListTile（读屏两个节点） | `ShunSwitchRow`（一个节点），新 key `host-pinned` |
| 底部操作栏 | Material elevation 3 | Prism 卡片那一层底色 + 上沿细线；三个按钮 `ShunButton`，key 不变 |
| 存为凭据、新建凭据、打开插件设置、改成直连 | Text/Outlined 按钮 | `ShunButton`，key 不变 |
| Tailscale 登录说明、Telnet 路线预览 | Container（surfaceContainerHighest、10 圆角） | Prism 卡片那一层底色和圆角；预览算不出来时仍用错误色 |
| 分组、密钥、凭据面板，「更多」类型面板 | ListTile 列表 | `ShunSection` + `ShunListRow`，当前那项打勾、读屏「已选中」；各 key 不变 |
| 路线编辑器的每一站 | Material Card | Prism 卡片那一层（`ShunSectionItem`），文字按钮换 `ShunButton`；上移 / 下移 / 移除仍是图标按钮 |
| 测试连接页 | 结果块 10 圆角，按钮 Material | 结果块 Prism 圆角（底色仍按成功 / 失败 / 提示分），「停止」「完成」换 `ShunButton`，「完成」新挂 key `probe-done` |

公共层只加了一项：`ShunListRow.selected`。当前那项交给 Prism 卡片自己报「已选中」（`isSelected`），别的在里面补「未选中」。两边都标会冲突、拆成两个节点（R87 分组 chip 撞过）。

保留 Material 的删除按钮：「删除此服务器」要红色描边，`ShunButton` 没有危险样式；记为兼容点（第 4 节）。

### 2.1 清点：迁移前后逐项对照

方法同 R86、R87：临时 widget 测试装起整个 App（假 SSH 服务，不碰网络），从 ⊕ 和 ⋮→编辑进表单，在 SSH 四种认证、高级展开、Mosh、Telnet、RustDesk、分组面板、密钥面板、「更多」面板、编辑带跳板 / 标签 / 置顶 / 目录来源的主机、测试连接进行中 / 成功 / 失败这些状态下导出读屏节点和带 key 的部件。原始输出 `form-before.txt`、`form-after.txt`，探针源码 `form_inventory_probe.dart.txt`（没留在仓库里）。

- 原 key 全在、顺序不变。在测试数据上把 lib 临时退回 HEAD 录了两串（新建并展开高级 27 个、编辑带跳板的主机 32 个），写成常驻测试「迁移前表单的入口一项不少、顺序不变」两条，录完 lib 已恢复。录第一次时测试视口只有 390×844，滚出去的部件被回收、只录到下半截，改成先把视口拉高再录。
- 新增 key：`host-pinned`、`probe-done`。
- 读屏变化：「高级」成了带展开状态的按钮；高级里各块小标题成了标题节点；置顶开关从两个节点变成一个；分组面板当前那项报「已选中」；「从 Tailscale 添加」「远程桌面」成了标题；分组选择框原来不是按钮，这批没改（它和输入框一个样子，R96 统一看）。
- 迁移前就有的两处并节点，本批修掉：高级展开后各块小标题和「添加跳板机」下拉框、「目录来源」被并成一个节点（带下拉框的按钮和展开状态）；Telnet 的「只能直连」说明和路线预览被并进「标签」输入框。读屏会把相邻、互不冲突的片段并成一个节点。

### 2.2 读屏容器只留必要的

第一版在五处加了「自成节点」（两处小标题、「连接时会这样走」、添加跳板机下拉框、Telnet 说明和预览）。逐个去掉再清点：

| 去掉 | 结果 | 处理 |
|---|---|---|
| ShunSection 小标题、表单块小标题这两处 | 读屏清点一模一样 | 删掉，ShunSection 回到 R86 写法 |
| 「连接时会这样走」 | 只差节点先后 | 删掉 |
| 下拉框（和上一行同时去掉时） | 「连接时会这样走」又并进下拉框 | 保留下拉框这层（输入控件本该自成节点） |
| Telnet 说明和预览 | 说明、预览连同「标签」输入框从读屏里消失 | 保留 |

留下的三处都有测试守着（3.2 的 M2、M3）。
