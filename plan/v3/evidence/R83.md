## 2. 主题映射

原则：预设的六个颜色（页面、正文、卡片、主色、边框、错误）是主题身份，页面、卡片、主色、边框原样用；只有正文、次要文字、错误色在页面或卡片上不到 4.5:1 时，沿 HCT 色调往远离底色的方向挪到刚好够（色相、彩度不变）。Material 各角色与 Prism 逐个相同，要改外观只改 `prism_theme.dart`。

### 2.1 颜色与表面

| 语义 | 浅色 | 深色 | 说明 |
|---|---|---|---|

### 2.4 动效

- 换主题（深/浅/系统、主题 ID）：当帧换好。宿主不包 AnimatedTheme、不用 ThemeCrossFade：前者会让后台终端的配色和 OSC 11 回答跟着插值抖动，后者会截整页旧帧盖在活终端上。
- 展开/收起（ExpansionTile：主机分组、Tailscale「高级」、连接记录等）：Prism `UnfoldEntryTransition.duration`（240ms），easeOutCubic / easeInCubic。主机编辑器的「高级」本来就是 Offstage 瞬间切换，不在此列。
- 系统「移除动画」（MediaQuery.disableAnimations）：Material 侧展开改 `AnimationStyle.noAnimation`；Prism 的 `motionDuration` 读同一个开关。
- 没有新增别的动效；终端正文无 LiquidGlass / BackdropFilter。

### 2.5 按钮字黑白：改善了一部分，剩下的留给 R96 取舍

- R81 按亮度 0.46 分黑白，124 套里 60 套按钮字不到 4.5:1。现在用 Prism/Flutter 公开的 `estimateBrightnessForColor`（亮度约 0.34 以上用黑字）：24 套由白变黑（深 17、浅 7），全部比原来清楚；不到 4.5:1 的降到 36 套。
- 剩下 36 套都是中等亮度主色配白字，其中 18 套不到 3:1（最低 2.74:1：base16-mocha、phonebook、深色 mondrian；深色 Pure Black / VS Code / Deep Blue / Graphite 约 2.97–2.99）。这些 R81 时就是同样的白字，本批没有变差。
- 本批一度在注释里写“和 Prism 部件同一条线”，核对后不对：Prism 从不自己调用这个函数，按钮和分段控件只读配色里的 onPrimary。注释已改，并加了回归断言：任何一套的按钮字都不能比 R81 更淡。
- 要全部到 4.5:1 只有两条路：主色上一律取黑白里对比更高的（会让默认 Snow 等 37 套的按钮字和开关圆点变黑），或像 FlClash/M3 那样给按钮底单独用更深的主色。这是外观取舍，本批不替所有者定，归 R96。

### 2.6 旧设置

uiThemeId 原样存、原样读；认不出的 ID 以及只在另一亮暗里存在的 ID 照旧落到 Midnight / Snow。设置 JSON、自定义背景引用 `shun-background:`、终端字号和输入方式字段都不变，没有迁移代码。同一设置只建一次主题对象：Prism ThemeData 没有 `==`，每次新建会让读主题的整棵树跟着重建。

- 自定义背景只用了 fixture 图（1px PNG、条纹渐变），没有真实照片。
- R81/R82 的失败记录、性能观察和 ABI 观察原样保留。
