# R55 远端 AI CLI 工具发现

日期：2026-10-12。基线提交：`9f02d063344613774369a1075787df6a5218c2aa`；本文件对应本地 R55 实现候选。这里只记录工具发现，不把文件存在、安装包版本或欢迎页当作登录、启动和原生继续成功。

## 实现与边界

- SSH 主机详情和已连接终端的快捷栏都能打开「AI 命令行工具」。终端入口绑定当前输入窗格；主机入口先核对保险库中的主机身份与冻结路线，能安全复用同主机同路线的活连接时复用，否则走既有每跳主机密钥验证、认证和代理/跳板路线建立临时查询连接。查询只开独立 `exec /bin/sh -s` 通道，不打开 PTY，不运行主机 startup，不向现有终端写字。
- 首批登记 `claude`、`codex`、`gemini`、`opencode`；扫描非交互 `PATH` 的前 64 项、界面声明的常见目录和用户补充的最多 16 个目录。还可补充最多 16 个「名称 + 可执行路径」的自定义工具；同一工具的不同安装路径分别列出。只检验文件存在且可执行，最多返回 64 个安装实例，查询总输出上限 64 KiB、总时限 10 秒，支持取消和关闭晚到通道。扫描设置只保存在本机加密存储，按源主机 ID、地址、端口和 SSH 用户隔离；结果不持久化。
- 不执行发现的 CLI，包括 `--version`。只在已知 npm 包相邻的至多两个明确位置读取每个最多 8192 字节的 `package.json`，并核对包名后显示「安装包标注版本（未运行工具核验）」。原生二进制、包装脚本和自定义工具的版本显示未知；没有把安装包数据当成可执行文件真伪、登录状态或启动/恢复能力证明。不会读取 CLI 凭据、source shell rc、安装/升级工具或调用模型。
- 探测失败只给本地固定错误文字，不回显远端 stderr 或原始输出；输出协议 NUL 分帧并核验完整性、字段、路径和数量。恶意路径按 POSIX 单引号传入脚本或在本地拒绝。缺失结果只称「此范围未发现」；alias、function、其他用户/容器、登录 shell 特有 PATH 和未来未知工具可能不在范围内。手动路径始终可补充，工具路径可复制到终端手动使用。

## 实际验证

工具链为 Flutter 3.44.4 / Dart 3.12.2。`flutter analyze --no-pub` 为 `No issues found`。`flutter test --no-pub -j 4 --exclude-tags ai-cli-ssh-fixture --reporter expanded` 为 **1128 通过、47 跳过、0 失败**。全量涵盖本轮 12 条探测协议/本机 POSIX/故障测试、3 条 widget 测试和原有回归；其中原有测试环境未启动的用例保留跳过状态。

为避免旧 `integration_ssh_fixture_test.dart` 重启共享 sshd 干扰，真实 SSH 组另用 `flutter test --no-pub test/ai_cli_ssh_fixture_test.dart --reporter expanded` 单独执行：**8 通过、0 失败**。本机 Docker 的 OpenSSH 环境覆盖 Direct、SOCKS、Jump、SOCKS+Jump，观察验证顺序、目标 client 查询、没有额外拨号/启动命令/CLI 执行、拒绝未知指纹后零查询、错误 SOCKS 口令不改走 Direct；活 `cat` 终端记录到的探测字节为零，并可继续收用户手动输入。单独的 `tool/ai-cli-fixture` 容器里真实安装了 Claude Code 2.1.292 与 Codex CLI 0.160.1；测试只读取可执行文件和安装包标注版本，未启动 CLI、登录或发送模型请求。

本机 POSIX 测试使用不会被执行的哨兵文件，覆盖多安装、去重、空格/中文/引号/命令替换字符、失效和不可执行路径、超限、损坏帧、超时、取消、晚到通道和输出上限。widget 测试覆盖主机与用户作用域的设置、刷新、关闭后迟到结果以及 360dp 快捷栏的触控宽度。此前一次独立测试在磁盘空间耗尽时未进入用例，随后用 `flutter clean` 释放编译缓存；OrbStack 的 VM 停止导致下一次连接被拒绝，重启本轮测试容器后得到上述 8 条通过结果。失败尝试不计作 PASS。

**证据边界**：本轮没有把候选装上 Android/iOS 设备，也没有连接所有者真实 SSH 主机、AI 账号或真实项目；没有验证真实 CLI 的登录、启动、对话继续或移动端交互。AIC01/AIC02 的 PASS 只指这里明确列出的本机 POSIX、widget 和真实 OpenSSH 隔离测试。AIC03–AIC09 仍 NOT_RUN，NET11 仍 FAIL；后续 R56 依赖的 R23 尚未完成。无 push、发布或生产账号/额度使用。
