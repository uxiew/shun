## 已接入行为

- 主机详情、活动终端的 AI 工具列表可选发现的具体可执行路径，再填项目目录；最近工作项可一键在同工具/同项目新建。项目预检使用同一冻结 RoutePlan，逐跳走现有指纹/认证/代理/跳板；只读确认目录、工具及 `pwd -P` 的实际目录，失败不改用 home。新建连接内再次校验目录和可执行文件。
- 普通模式新开专用 SSH PTY，用结构化 `AiCliLaunchSpec` 生成 POSIX `/bin/sh` 命令；路径和参数单独校验、单引号转义，拒绝控制字符、非绝对工具路径及过长参数。主机 startup 不运行，已有终端不收命令。断线恢复沿 R23 打开普通新 shell，不再次执行工具；工具正常退出停在标签内提示，不自动重启。
- 可明确选择默认 socket 上的专属 tmux session。名称 `shun-ai-<本次 UUID>`，先取得完整 server/session 身份，再读取唯一 window/pane/pane PID；向经核对的 pane 发送一次启动命令。只附着该目标，不踢走其他客户端。结果不明展示本次名字供人工核查，不自动重试、清理或杀掉可能已创建的目标。新建和附着均由用户动作触发，Probe/Restore/冷启动不新建。
- UI 启动中禁用重复操作，controller 消耗请求 ID；SSH exec 发起后即把断网/取消/超时报为“结果未知”，不把未知当成功。tmux 会话名本身亦阻止同一 ID 创建第二个同名目标。成功进入新标签后才写最近工作记录。工具登录、权限和模型 token 留给工具自身，不向 App 提供或存储。
