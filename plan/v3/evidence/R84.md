- Prism `InputDecoration` 没有 `labelText`（浮动标签）；shun 表单和 FormGap 20dp 都按浮动标签定，换过去所有表单的标签没了。

## 4. 扫描器

### 4.1 怎么认

旧扫描器只认写死的名字：输入框是 `TextField/TextFormField/DropdownButtonFormField`，段落是最内层调用为 `LText/Text/…`，打码框靠正则找 `obscureText:` 所在的 `TextField(`。新引擎（`test/support/ui_rules.dart`）：

1. 类名归一：读每个文件给 prism_ui 起的导入别名（不只认 `prism.`；不带别名导入也认），Prism 的类记成 `prism.X`，和 Material 同名类分开。
2. 文字角色发现：对本地和 Prism 的每个 Widget 类（含其 State 类），追它的 `String` 字段流到哪里——交给 `Text/LText` 的是正文（≤30），落在 `helperText:` 的是提示（≤16），落在 `subtitle:` 里的是副标题（≤16），交给另一个已知角色的类就继承那个角色。迭代到不再变化（读源码加发现约 1.7 秒）。`localized(…)` 透明。
3. 输入框发现：类体里恰好一个输入框、自己不是对话框/面板/整页的类，算输入框（发现了 `_AdvancedNumberField`、`LoginChoiceField`、Prism 的 `TextFormField/SecretTextFormField/SearchField` 等）。横排 `Row/Wrap` 的 children 不查 FormGap。
4. 打码类发现：类体里有 `obscureText:` 框却没把三个开关全关的类（Prism 的也算，输入框原语除外——它们把开关交给调用处，调用处照旧逐个查）。lib 里调用这些类就报。

确认框、SnackBar、Tooltip、ⓘ（`showHint`/`HintButton`）以及 `tooltip:`/`semanticsLabel:` 参数仍不算常驻。`HintTitle` 从「整个不查」改成只有 `hint` 不查、标题照查。

## 7. 锁文件事故（已还原）

为清 analyzer 提示跑了不带 `--no-pub` 的 `flutter analyze`。它先做 `pub get`，本机全局 `PUB_HOSTED_URL` 指向镜像，结果按镜像重新解析：`pubspec.lock` 改了 438 行（archive 4.3.0→4.7.1 等一批传递依赖升级、url 改成镜像），`.dart_tool/package_config.json` 跟着指向新版本。

处理：`git checkout HEAD -- pubspec.lock`；`env -u PUB_HOSTED_URL -u FLUTTER_STORAGE_BASE_URL flutter pub get --enforce-lockfile --offline` 按锁文件从本机缓存装回，核对 lock SHA256 回到 `43f68763…`、package_config 指回 archive-4.3.0、asn1lib-1.6.5、prism_ui `63450c0`。事故之后、还原之前跑的测试（4 个文件 36 项、一次被中止的全量）全部作废；第 8 节的数字都是还原后重跑的。变异校准、旧扫描器对照和图库截图都在事故之前完成，用的是锁定依赖。`docs/dev/README.md` 的命令改成 `flutter analyze --no-pub` 并写了还原步骤。
