## 结论先说

- 终端下面现在有三种打字方式：系统键盘直接打进终端（原来的）、App 自己的**按键面板**、**大输入框**。快捷键栏行尾的 ⌨ 按钮进面板，
  面板里左右滑动在按键面板和大输入框之间切，面板右上角的 ⌨ 换回系统键盘。用过哪种记在设置里，下次打开终端还是它。
- 按键面板四页（常用 / 符号 / 组合键 / F 键，有自定义快捷键时多一页），每页的键整个露在面板里、不用滚，每个键至少 48dp。
  所有键都走原来的 `sendKey`/`sendText`，和快捷键栏同一个出口、同一套修饰键；模拟器上远端逐字节核对两个引擎都对（经 SSH 和经 Mosh）。
- 大输入框：输入法的候选、改字、语音都在框里完成，「发送」= 内容 + 回车，「只填入」不回车，「清空」。发法和 R19 的粘贴一样（多行照实写会不会逐行执行），
  目标照 R19 认「从空变成有字那一刻」的连接：断了不发、恢复成新连接也不发，要点「改发到新连接」，发出去才清空。模拟器上回放的微信语音、拼音逐字节对，
  发到真 bash 的效果和提醒文字一致。
- 打开/收起面板、面板和系统键盘互换、点进大输入框：模拟器上远端每次最多收到 **1 次**窗口尺寸变化，最后的行列和引擎的行列一致。
- 横屏、Mosh 标签、两个引擎在模拟器上都跑过；横屏每页摆成两行。分屏只在页面测试里测过（键发给点过的那一格）。
- 没做：真机（微信输入法语音进大输入框）、TalkBack 真读屏、整套 QWERTY 字母键盘、草稿存盘。见「没做的」。

怎么用（使用手册 `docs/user/README.md` 第 9 节「按键面板和大输入框」写给用户的版本）：

1. 终端页快捷键栏行尾的 ⌨「按键面板和大输入框」→ 系统键盘收下去、面板顶上来。
2. 面板里**往左滑**（或点左上第二个标签）到大输入框；往右滑回按键面板。
3. 面板右上角 ⌨「换回系统键盘」→ 面板收起、系统键盘弹出。点「收起键盘」或返回键收起面板，再点终端就展开上次的方式。

## 设计取舍（为什么这么做）

| 问题 | 怎么定的 | 理由 |
|---|---|---|
| 面板多高 | 占系统键盘的位置：记住这个方向上系统键盘升起来的高度（收键盘那一刻存，键盘升的过程中不覆盖），面板高 = 键盘盖住终端页的那一截；没见过键盘时按屏幕估。最低竖屏 256dp、横屏 156dp，最高终端页的 55% | 切换时终端高度尽量不变；回放输入法只有 200dp 还盖住导航栏，照它开面板只剩一百来 dp、后两行键被剪掉，设备测试点到底下的导航栏（见本机手册撞墙），所以要最低高度 |
| 切换时尺寸抖 | 面板切换的那 400ms 里适配器先不把尺寸发给远端（`holdResize`），到点只发最后一个；从面板换回系统键盘时，键盘升上来之前（最多 700ms）面板的位置先空着；键盘收起时手势条留白（24dp）的那几帧也补上 | 不这么做模拟器上量到 2 次：先变高再被压回去、导航栏留白多出一行。vim、htop 每收到一次就重画一次 |
| 有没有整套 QWERTY | 没做，面板上没有字母键。要 Ctrl+字母用「组合键」页，或者在面板上亮起 Ctrl 再换回系统键盘打字母（Ctrl 还亮着，套在下一个字上） | 字母、中文系统键盘比我们做得好（联想、语音、手写）；面板补的是系统键盘上难找的键。所有者说 QWERTY 可选，要的话再加一页 |
| 修饰键 | 面板的 Ctrl/Alt/Shift 和快捷键栏是同一个（R18 的一次性语义）：按一下亮、套在下一个键上就灭，换页带着走；切标签、换格、切到后台熄灭 | 一个终端只有一份修饰键状态，两处各一份会对不上 |
| 大输入框怎么发 | 和 R19 的粘贴同一个函数（`pasteInto` + `PasteReview`）：去掉控制字符和末尾换行；没开 bracketed paste 时换行变回车，照实写「前面各行一发出去就执行」，那段话和粘贴预览共用一份 | 一件事只写一处，提醒和粘贴预览不会对不上 |
| 发给谁 | 每个标签一份草稿；框从空变成有字时记下这个标签当时的连接（R19 的规矩）。断了：按钮变灰、说明原因、不发；恢复成新连接：不发，点「改发到新连接」才改认；关掉的标签有字的挪到别的标签框上面（放进来 / 复制 / 丢掉）。只有真发出去才清空 | 打了一半断线、自动恢复以后，原来的 shell 状态（目录、环境、正在跑的程序）都没了，不能替用户决定继续发 |
| 草稿存不存 | 只在内存里，App 被杀就没了；开了「系统安全键盘」时框也不联想、不学习 | 框里可能是密码、token，存盘要加密和清理策略，第一部分不做 |
| 面板开着点终端 | 不叫系统键盘，收起时点终端重新展开面板 | 用着面板就是不想要系统键盘；点终端是想打字 |
| 横屏 | 每页两行（常用页两行×12 个）；面板开着时标签条收起；大输入框里弹着系统键盘时快捷键栏让出来、框只留一行 | 横屏高只有 411dp，要给终端留行 |
| 分屏 | 面板的键发给点过的那一格（和快捷键栏一样）；大输入框发给当前标签的那一格 | 沿用 R18 分屏的规矩 |
