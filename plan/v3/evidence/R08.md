## 做了什么

- **连接尝试由调用方持有**（`ConnectionAttempt`，`lib/infrastructure/ssh/ssh_service.dart`）：带代次号；调用方在拨号开始前就能取消。
  失败或取消统一关掉这次尝试已建好的一切（PTY 通道 → 各跳 client 逆序 → 还没被 client 接管的 socket）；成功后所有权移交会话，之后再取消只标失效。
- **每个标签一个代次**（`SessionController._attempts`）：新开和恢复都登记；结果只有「仍是登记的那一次、没被取消、controller 还活着」才算数，否则立刻关掉。
  这就是 docs/03 里建议的 ConnectionCoordinator/Lease 的落地形态，没有另起一个类。
- **恢复沿用冻结路线**：会话记住建连时的 `RoutePlan`（含每跳主机与私钥副本），自动恢复直接用它。
- **释放**：断线即释放这一代的网络资源；关标签先失效、再改界面、最后释放；controller 销毁时关闭全部；`abort`/`close`/`detachOutput` 都可重复调用。
- **连接回写**：最近连接时间、系统识别只补字段、基于保险库最新数据、主机已删就不写，并与主机编辑排队执行。
- **阶段事件**：按顺序上报，取消或移交后丢弃；等待页显示「第 i/n 跳，“x”：SSH 握手、核对指纹、登录」之类。
- **无全局跳板池**：没有新增任何跨连接共享；每条终端连接自己连跳板（集成测试验证）。外部 SOCKS 只关 App 自己那条到代理的连接。

## 修掉的具体缺陷

| 缺陷 | 以前的后果 | 怎么证明修了 |
|---|---|---|
| 恢复进行中关标签，恢复出来的连接没人关 | 服务器上一直挂一条 SSH 连接 | 集成：关标签后边缘机 ESTABLISHED 回到 0 |
| shell 里 `exit` 或断线后，目标和跳板 client 不关 | 每恢复一次多留一整条链路 | 单测 `aborted`；LIFE06 每次采样两端 0 条 |
| 等保险库解锁时取消无效 | 先连上再关 | 单测：取消后 SshService 一次都没被调用 |
| 失败时已拨通但未被 client 接管的 TCP 不关（如坏私钥） | 半开连接留到对端超时 | 单测：服务器端 socket 读到结束，报错指明「读取登录私钥失败」这一跳 |
| 关标签先 await 关闭再写回旧快照 | 期间连上的新标签被抹掉且连接不关 | 单测；把顺序改回旧写法后该测试失败 |
| 恢复时目标用旧快照、跳板/代理按新配置现算 | 路线一半新一半旧 | 单测断言传入的就是原 plan；集成 NET10 恢复仍走 dante |
| 连接回写用整份旧快照（upsertHost） | 连接期间的编辑被改回，已删主机被复活 | 单测三条；去掉排队后「编辑还在保存时回写到达」那条失败 |
| controller 销毁只停监控 | 应用退出时 SSH 连接留着 | 单测；LIFE06 每 5 轮销毁一次 controller，两端 0 条 |
| 取消后 connect 也正常返回（上游就有） | 点了「终止连接」，主机列表页还弹「xx 已连接」 | connect 返回 bool，单测断言取消/迟到为 false |

## 反向验证（测试确实能抓住原来的缺陷）

- 把 `markConnected` 改回不排队：「编辑还在保存时连接回写到达」失败。
- 把关标签改回「先 await 关闭再写回快照」：「关标签时另一个连接恰好连上」失败（假会话的 close 要真的让出一次事件循环才暴露，已写进测试替身）。

## 这台机器上的坑

OpenSSH 10 的来源罚时（PerSourcePenalties）：连上不认证就断每次罚 1 秒，累计过 15 秒拒绝本机全部新连接。LIFE06 跑 500 轮时边缘机开始 `drop connection ... penalty`，
后面所有 SSH 测试都连不上。fixture 里已关（`entrypoint.sh`），README 写了症状。真实服务器上反复在指纹确认时取消也会触发它，这是服务器行为，App 不做绕过。

本次会话里磁盘可用空间在 0–47 GB 之间大幅波动（本项目 build + .dart_tool 共 0.7 GB，主要是系统换页和别的进程），一次全量测试因 `No space left on device` 中断后重跑。

## 未测项与局限

- 用户在指纹确认弹窗上时取消连接：连接会马上断，但弹窗还留在屏幕上，点什么都不再有效果（dartssh2 的回调落在已关的 client 上，实测无未捕获异常）。弹窗随取消关闭属 R09 的信任界面。
- TCP 拨号进行中无法中途中止（沿用 R06 的局限）：取消马上返回，那次拨号到期或连上后才被关。
- 主机写入排队只覆盖 VaultController 自己的主机写入；设置页导入、钥匙串、云同步仍直接 `replace`，和它们交叠时仍可能后写覆盖先写。
- 借用连接的 SFTP、服务器监控、端口转发：断线后随之失效（端口转发已实测），但界面上不会自动撤掉条目、SFTP 不会提示「连接已换代」。属 R24。
- 设备上未跑。
