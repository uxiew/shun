## 替所有者定的

- 不迁移。主机自带的密码、私钥照常能连，编辑器里没有私钥下拉框了，要用私钥就建凭据。
- 选凭据并保存时清掉主机上的密码和私钥引用。不清的话，没存密码的凭据写着「连接时问」却发旧密码。保存前切回去不丢。
- 存为凭据时「自动 + 私钥 + 密码」变成「SSH 密钥 + 密码」，展开后还是自动，登录行为不变。
- 主机用户名同步成凭据的，改凭据时引用它的主机跟着改。
- 代理只能选存了密码的密码类凭据；桌面端不认代理上的凭据（手册写了）。
- WebDAV、S3、AI key、Tailscale API key 不进凭据。Tailscale SSH 模式不留凭据引用。
