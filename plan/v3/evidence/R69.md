## 做了什么

F31。每个连接的认证二选一（所有者 11-01 补充「连接可选简单的用户/密码还是认证」）：用户名密码直接填，或者从「凭据」选。主机编辑器、首次登录、Tailscale 设置和导入、代理都是这样，选完回显名称、用户名和方式。凭据四种：密码、SSH 密钥、安全密钥、SSH 密钥 + 密码。

Royal TS/TSX 的做法：连接可以用凭据对象（能复用、能继承父文件夹），也可以直接填用户名密码，还能连接时弹选择框。没查到它的私钥、口令凭据类型。

## 跑起来才发现的

新建凭据对话框里「名称」「密码」的提示被截断（「密码（可选，不填…」），字段间隔不一样，密钥 + 密码那句说明太长，都改了，细节留在手册。

## 替所有者定的

- 不迁移。主机自带的密码、私钥照常能连，编辑器里没有私钥下拉框了，要用私钥就建凭据。
- 选凭据并保存时清掉主机上的密码和私钥引用。不清的话，没存密码的凭据写着「连接时问」却发旧密码。保存前切回去不丢。
- 存为凭据时「自动 + 私钥 + 密码」变成「SSH 密钥 + 密码」，展开后还是自动，登录行为不变。
- 主机用户名同步成凭据的，改凭据时引用它的主机跟着改。
- 代理只能选存了密码的密码类凭据；桌面端不认代理上的凭据（手册写了）。
- WebDAV、S3、AI key、Tailscale API key 不进凭据。Tailscale SSH 模式不留凭据引用。
