## 2. 设置页校准（第一张完整页）

FlClash 固定版本的设置类页面（`lib/views/config/*`、`lib/ui/list_item.dart`）是：Prism `generateSection` 分组 + 每行一张 Prism `DecorationListItem` 卡片（首尾圆角、行间细线），右侧放开关、「›」或「值 ⌃⌄」弹出菜单。shun 设置页按这个改写，项、分组、顺序、key、保存时机照旧。

公共层（`ui/components.dart`）为此补了：

| 部件 | 作用 | 读屏 |
|---|---|---|
| `ShunSection` | 分组小标题（Prism ListHeader，带 header 语义；有 hint 时 ⓘ 在最右）+ `generateGroup` | 标题是 header 节点，ⓘ 独立 |
| `ShunListRow`（扩展） | 放进分组时画成 `DecorationListItem`；`chevron` 画 Prism「›」；`details` 放指纹、地址这类多行内容 | 一行一个按钮节点，名字和点按在同一个节点上 |
| `ShunSwitchRow`（新） | 点整行切换，右边 Prism 开关，可带 ⓘ | 和 HintSwitchTile 一样两个节点：带开关状态的行、独立的 ⓘ |
| `ShunOptionsRow`（新） | 「标题 … 当前值 ⌃⌄」，点整行弹 Prism 菜单，当前值打勾 | 一个按钮节点，念标题和当前值 |
| `ShunSectionItem`（新） | 组里放滑块、分段、预览：同样的底色和首尾圆角、底边细线 | 一个普通分组节点，不是按钮 |

Prism 的卡片（CardSurface）不管能不能点都是一个按钮语义节点。第一版照常在外面套自己的语义节点，清点时实测每行变成「有名字不能点」和「能点没名字」两个节点，自由内容块多出「不可用的按钮」。改成：分组行的名字直接并进卡片节点；自由内容块不用 Prism 卡片，只画同样的底色和圆角。两处都加了回归（第 5 节变异 MC、MD）。

### 2.1 清点：迁移前后逐项对照

方法：迁移前后各在同一份 widget 测试里装起整个 App、进设置页，按顺序导出读屏节点（名字、按钮/开关/选中状态、能否点）和所有带 key 的部件。原始输出归档在 `../.toolchain/artifacts/r86-settings-20261114/settings-before.txt`、`settings-after.txt`，探针源码 `settings_inventory_probe.dart.txt`（没留在仓库里）。

- 桌面测试里 `Platform.isAndroid` 为假，插件组（UU 远程、RustDesk、插件）、应用锁、发到/接收另一台手机这 6 项看不到，逐项核对源码：都在，key、条件、跳转都没变；隐藏的主机仍在「安全」组，插件三项仍在「插件」组。

### 2.2 看得见的变化

- 分组卡片、Prism 开关和滑块；分组小标题是 Prism 的 headline 字阶（灰色），ⓘ 移到小标题最右边。
- 深色/浅色/系统、全局背景/仅终端、中文/英文改用 `ChoiceSegments`（去掉了图标）。
- 快捷键高度、方向键长按连发、背景对齐方式、离开多久后锁：Material 下拉换成 Prism 弹出菜单。
- 终端字号的示意行不再被读屏念出（纯示意）。
- 切换界面语言：`LText` 以前不依赖语言，写成 const 的文字切语言后不变；迁移把「界面语言」变成 const 后暴露出来（`r25_settings_test` 当场失败）。现在 `LText` 和公共控件取文字时登记对语言的依赖（`localizedOf`），整页当场换。
