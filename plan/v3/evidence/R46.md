## 测出来的问题

- **最近任务缩略图露主机列表。** 原设计靠 Dart 在 onPause 时画遮罩，模拟器上系统截图更快，主机名清清楚楚。改成 `MainActivity.onPause` 加 FLAG_SECURE、`onResume` 按原决定恢复。
- **关闭应用锁时会再锁一次。** 设置页直接调系统验证，PIN 页把 App 顶到后台，回来按「离开过」算。单测的假验证不走生命周期，测不出来。现在都走 `AppLockController.confirm`。
- **回来后终端丢焦点。** 原来盖一下就拿走焦点。现在只有真锁着才拿走，解锁后还回去。
- **一条没查清的：** 改焦点之前跑设备流程 3 次，有 2 次终端页 `terminal_screen.dart:259` 报布局溢出 18 像素（只有调试版报，没抓到是哪一步），其中一次是测试绕过按钮直接进画中画。改焦点之后又跑 2 次都没再见到，样本不够，不能说已经没了。不开应用锁跑了 1 次也没见到。

## 设计决定

- 用框架的 `BiometricPrompt` 自写 Kotlin 桥，不用 `local_auth`：它要 `FragmentActivity`，换基类要重测 R22。
- 手机后来去掉屏幕锁时放行：能去掉屏幕锁的人本来就过得了验证，卡死只会把机主锁在外面。
- 从选文件、扫码、权限框回来最少宽限 60 秒，超了照锁。
- 保活通知不用改：它只写数字（`session_controller.dart` 的 `_syncKeepAlive`），没有主机名。
- 应用锁设置不进保险库，不会被同步或互传改掉。

## 验收对照

- 锁着时后台恢复照 SEC07：没有改 `connection_lifecycle.dart`，应用锁不碰连接。
- 不自建密码体系：只有系统验证，没有任何存下来的口令。
- 解锁失败或取消不露内容：见上面 `stayedLockedAfterCancel`、`hidesHost`。
- 解锁不自动批准签名、访问请求或网关动作：`AppLockController` 不引用那些流程，它们也不读锁的状态（`grep appLock lib` 只有应用锁自己、`app.dart`、设置页和 sudo 键，sudo 键调 `confirm` 只是多要一次验证，见 `evidence/R66.md`）。

## 没测的

- **面容**：模拟器没有。「允许弱生物识别」开关只验了存取，弱生物识别的弹框没见过。
- **真机**：没装过。
- **其它 Android 版本**：API 24–29 的弹框和 API 33 的 `setRecentsScreenshotEnabled` 都没真跑，JVM 单测只钉路由。手上只有 API 30 模拟器。
- **画中画窗口被关掉之后的缩略图**：那条路没有 onPause，卡片可能还是最后一帧。API 33 起有 `setRecentsScreenshotEnabled` 兑底。
- **TalkBack**：锁屏页读屏念不到底下的主机，只在 widget 测试和 uiautomator 的无障碍树里验过，没开真的 TalkBack。
