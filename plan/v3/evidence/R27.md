## 发现（正式 R27 之前要处理或要所有者定）

1. **Gradle 这层没有任何校验**：没有依赖锁，没有校验元数据，wrapper 也不核对 Gradle 发行包的 hash。pub、Ghostty、mosh 都按 hash 拉，
   唯独 Gradle 拉的 178 个 Java/Kotlin 依赖和 Gradle 本身不核对。SUP01 一直卡在这里；STATUS「发布前要定的」里已有这一条，所有者还没定。
2. **CI 打的包没有本机发布脚本的那几道检查**，而手册说给别人的包用 CI 的：
   - `.github/workflows/mobile.yml` 直接 `flutter build apk --release`，不查 16 KiB 对齐，也不核对 `libghostty.so` 是不是从源码编出来的那份。CI 每次都是全新环境，缓存被改的风险比本机小，但对齐这道检查没有。
   - `flutter pub get` 没加 `--enforce-lockfile`：锁文件和 pubspec 对不上时，它会重新解析、改写锁文件接着编，而不是报错停下。
   - 四个 Action（`actions/checkout@v4`、`mlugg/setup-zig@v2`、`subosito/flutter-action@v2`、`actions/upload-artifact@v4`）按 tag 引用，不按提交号，tag 被改了 CI 会照用。
3. **主 App 的许可材料不够分发用**（Mosh 插件那份 `LICENSES.md` 倒是齐的）：
   - 根目录 `LICENSE` 只有 11 行声明，没有 GPL-3.0 全文（R00 记过，到现在没补）。
   - App 里只有设置页底部一行「shun x · GPL-3.0-or-later」加「基于 Netcatty Mobile 修改」。GPL 第 5 条 d 款要求交互界面显示「适当的法律声明」，包括不提供担保、怎么查看许可全文；这两样现在都没有。
   - 包里有 Flutter 自动生成的第三方许可 `NOTICES.Z`，但 App 里没有入口能看到（没用 `showLicensePage`）；Gradle 那 178 个依赖和 Ghostty 的许可也不在里面。
   - 要不要补、补成什么样，取决于分发形态（STATUS「发布前要定的」第一条），这次没动。
4. **R26 候选怎么装到手机上**：手机上的 `top.xdwa.shun` 是 10-21 装的 CI 包（versionCode 2，正式密钥签）。本机包用 debug 证书签，装不上去，
   要装只能先卸载，而卸载会清掉所有者的保险库。三条路都要所有者定：用 `../.toolchain/android-signing` 里那把正式密钥在本机签候选包（要授权）；
   推送后让 CI 打（要授权推送）；或者所有者自己先导出、卸载，再装本机包。

## 没做的

- **真机**：没往 Pixel 9 Pro 装本次的包，原因是上面第 4 条。手机信息只读了一次：Android 17（API 37）、4 KiB 页、只有 `arm64-v8a`、已装包的版本和签名摘要。
- **16 KiB 真机**：Pixel 9 Pro 现在是 4 KiB 页。16 KiB 只在 R04 的模拟器（API 36）上跑过，这次没再跑。
- **冷环境重建（REL01、SUP01）**：这次只清了原生库缓存，没有清空 pub 缓存和 Gradle 缓存、在新目录里从头编，也没有对比两次编出的 APK。
- **SBOM**：没生成。Gradle 依赖清单在 `gradle-release-runtime.txt`，只是原料。
- **正式签名、CI 包**：没用正式密钥，没推送、没让 CI 打包。
- **最低 API**：只在 API 30 上跑了 release 包；R04 在 API 24–28 跑的是当时的 spike 包，不是这个候选。
- REL02 里「无 secret 日志」这次只看了崩溃和 VM service，没有像 R28 那样放标记、全量搜。

## 走过的弯路

- 第一次连 Mosh 显示 `mosh: Nothing received from server on UDP`。是我在界面上建主机时没填「Mosh UDP 端口范围」，mosh-server 按默认 `60001:60999`
  绑了 60001，而测试环境只转发 60101–60108。在主机编辑页「高级 → Mosh 启动参数」填 `60101:60108` 后就通了。不是 App 的问题。
- 列 Gradle 依赖时在 `android/` 下 source 了 `env.sh`，它检查当前目录、直接返回，`GRADLE_USER_HOME` 没设上，gradlew 跑去重下 Gradle、连接被拒。回到 `shun/` 下 source 就好。
