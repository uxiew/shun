## 做了什么

- **冻结官方协议**：`netease-uuyc/uuremote-integration-guide` 提交 `be7d8109`，README sha256 `72f9017b…7bac45`，连同官方 Android 示例存到仓库外 `../.toolchain/artifacts/`。逐条口径与本 App 做法见 docs/17「X06 固定的官方口径」，其中三件官方没写的事（签名证书、回调怎么编码、ID 长度字符集）标明要真实 UU 复核。
- **内置 provider** `builtin.uuremote`：只有 `remote-desktop-external` 能力，路线只有 `provider-managed`，平台只写 Android；外部包冒用这个 ID 被拒。
- **请求**（`lib/infrastructure/plugins/uuremote_adapter.dart`）：参数只编码一次，和官方示例的 `Uri.encode` 一致；绑定每次带 UUID v4 的 nonce，callback 里再带一次性 `state`（官方保证回调时保留 callback 原参数）；全屏不带 callback。
- **回调校验**：自己切查询串、每个值只解一次，`+` 按字面（加密 ID 常是 base64）；同名参数出现两次、成功失败同时有或都没有、超长、控制字符、坏编码一律拒收。
- **状态机**（`lib/application/uuremote.dart`）：同一时刻只有一个等回调的请求，存在独立加密存储里（本 App 被杀后回调冷启动仍能对上）；state/nonce 对上即作废，重放、迟到、过期、类型不符都不算数；绑定成功先要用户确认挂到哪台主机，回调之后从不自动远控；全屏只记「已交给 UU」，小窗只记 UU 报告的结果和时间（`ExternalLaunchPhase` 本来就没有 connected）；`device_not_found` 只把这条 UU 绑定标失效；SSH 经代理/跳板的主机，不确认「UU 走自己的网络」就不发，判定复用插件契约 `checkRoute`。UU 这边只看得到主机 id、名字、路线。
- **证书信任**：官方文档没给证书。第三轮从官方 APK 读出一张固定在 `officialSigners`：那张证书签的 UU 直接可用；别的证书要用户看过后批准（同插件批准），再变就停下要求重新核对。平台层发送前再核一次证书，用显式包名发，别的 App 声明同一 scheme 拿不到请求。
- **Android**（`UuRemoteBridge.kt`）：按官方方式查 `uuremote://` 的解析者，另读官方包的版本和系统报告的证书，顺带查有没有别的包也声明了本 App 的回调地址；回调由过路的 `UuCallbackActivity` 接（第一轮是 MainActivity 直接接，第二轮改的，原因见下面「系统里留下什么」），原文排队后交给 Dart 同一个校验器，冷启动和运行中走同一条路；不写日志。
- **界面**：主机详情加「UU 远程」→ 每台主机的 UU 页；设置里「UU 远程」总览；首页外挂 `UuRemoteListener`，绑定回来在任何页面弹确认框。
- **设备关联**：`deviceLinksOf` 把 SSH 主机、目录设备（X05，存在主机的目录绑定上）、UU 绑定（存在 UU 自己的加密存储里，记主机 id）拼成一条；引用用本 App 起的绑定 ID，不用加密设备标识。X05 的 `catalogDeviceLinks` 改为调用它，规则只留一处。
- **落点**：计划写 `infrastructure/plugins/uuremote_adapter`（照做）；状态机在 application 层，理由同 X05（要用保险库和 registry）。

## 过程中发现并修掉的

- **模拟器上发现：限定了 host 的 App 对本 App 不可见**（e1bba5f）。官方文档的 `<queries>` 只写 scheme，系统拿 `uuremote:`（没有 host）去匹配，冒名包的 intent-filter 限定了 `host=external` 就匹配不上，页面不会提醒「另有 App 也声明…」。加一条带 host 的查询后正常。
- **翻译片段表误伤**：一开始把带时间和错误码的整句交给片段表，短片段「连接失败」放在最前面，把别处已有的「经代理连接失败」拆成了半中半英。改成先按精确表翻各段再拼。
- 覆盖率测试按行抓引号：`'no_device' => '中文'` 这类一行里先有英文字面量的写法会被误判。协议错误码做成了常量（`UuBindErrors`、`UuReasons`）。
