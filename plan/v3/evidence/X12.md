## 结论先说

- **作者入口** `docs/plugin-authors/README.md`：八步从零做出插件（环境 → 复制样例 → 自己的密钥 → 宿主证书 → 构建 → 安装 → 批准 → 连接测试/会话测试），
  另有接口约定（contract.md）、出错对照（troubleshooting.md）、版本兼容（compatibility.md）、许可（licensing.md）。不需要宿主源码和宿主私钥。
- **样例** `plugins/example`（Hello 终端，包名 `example.xwshun.hello`、pluginId `example.hello_terminal`）：独立 Gradle 工程、自带 wrapper，只依赖 `provider-sdk`；
  复制到仓库外、换一把新密钥照样 6 秒编出来。模拟器上走通授权 → 版本协商 → 字节流 → 改尺寸 → 关闭（宿主关、插件自己关）→ 设置页 → 停用/启用 → 卸载重装，
  正式版（release）宿主下照样可用。
- **宿主为此改了三处**：插件页底部显示本 App 的签名证书和插件 API 版本（作者要抄进插件）；详情页加「会话测试」（第三方终端插件原来没有任何界面能开会话，
  作者只拿宿主 APK 走不完流程）；修了一个崩溃——**插件在握手里抛 `IllegalStateException` 以外的异常，宿主整个闪退**（模拟器上先复现、再验修复）。
- 读生成代码发现：**旧插件不认识新追加的 AIDL 方法时 Binder 不报错**（void 方法看着像成功），原注释写反了。改了注释和文档，行为没改，留给以后加方法时按 minor 判断。
- **顺手修了 X09 留下的坑**：详情页「连接测试」原来每次重新 connect，Kotlin 桥先断旧连接，开着的 Mosh 标签被断成「被停用、撤销」。
  现在先 ping，连着就沿用、不重新握手；页面只断自己开的、且没有别的会话在用的连接；有会话在跑时不给「断开」。会话测试同样。
- 申请了 `own-session-ephemeral-secret` 的插件（Mosh）不给会话测试：没有 bootstrap 材料，宁可不开、写明原因，也不发半截会话。
- 许可：所有者 10-07 定了 SDK（`packages/plugin_api`、`plugins/provider-sdk`、`plan/v3/contracts`）和样例改 Apache-2.0，改前和基座逐行比对过、没有从 Netcatty 搬来的代码；宿主、Mosh 插件仍 GPL；不声称独立 APK 规避 GPL/AGPL。
- `xwshun.mosh` 按所有者 10-07 的决定绑到 Mosh 插件现在的测试作者证书，别的证书签的冒充者直接已拒绝。
