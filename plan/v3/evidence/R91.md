## 2. 迁移边界与做法

和 R88 / R89 一样，**输入框、AlertDialog 外壳、下拉、TabBar、筛选 chip 保持 Material**；换的是按钮、卡片、列表行、状态色和网络图。

| 部位 | 迁移前 | 迁移后 |
|---|---|---|
| 各确认框、sudo 提示、tmux 新建 / 重命名、Docker 拉取、进程调优先级、Caddy 编辑的按钮；各页「重试」 | Text / Filled 按钮 | `ShunButton`（内部仍是 Text / FilledButton，原 key 如 `sudo-continue`、`caddy-save` 沿用） |
| 进程、服务、tmux、Docker 容器 / 镜像、Compose 项目、概览的各张卡 | Material `Card` | 新的 `ManagementCard`：用 `ShunSectionItem` 画 Prism 分组卡片底色和圆角，不多出「不可用的按钮」节点；里面的 ExpansionTile / ListTile 照旧（同 R88 连接记录的做法） |
| Caddy 站点 | Card + ListTile | `ShunSection` + `ShunListRow`（key `caddy-site-<id>`），点行编辑，行尾菜单照旧，忙时整行禁用 |
| tmux「本标签附着在…」 | Card + ListTile + 文字按钮 | `ShunSection` + `ShunListRow`，行尾 `ShunButton`「分离本标签」 |
| 容器 / Compose / 服务的状态点、概览负载点 | 写死 `Colors.green/orange/grey/redAccent/blueGrey` | 主题色：运行 primary、暂停 tertiary、停止 outline、失败 error、未知 onSurfaceVariant |
| 网络吞吐图 | 图例在概览里另画（`Icons.remove`），断线后线条照常 | 图例画在图里（key `network-legend-rx/-tx`，和画线同色）；新参数 `stale`：断线后线条和图例降到 45% 不透明并标「断开前的数据」（key `network-chart-stale`），按住仍能看断开前的读数 |

`server_network_chart` 保留自绘：Prism 没有图表组件；唯一使用处是概览页（`ServerOverviewPanel`）。颜色全部取自主题（primary / tertiary / onSurfaceVariant / outlineVariant / inverseSurface），深浅色都由测试核对。

断线状态没改语义：概览留着断开前的数并写明读取时间（`monitor-disconnected`）；进程、tmux、Docker、服务、Caddy 整页 `AbsorbPointer` + 40% 不透明，顶上写明原因（`system-management-disconnected`）。
