## 没测的（都在 SYN04 里）

- **两台手机**：真的局域网、手机热点，没走过。
- **真扫码**：相机对着屏幕能不能读出来。模拟器试过一次虚拟场景（`-camera-back virtualscene -virtualscene-poster`），无窗口模式下系统里是 0 个相机，放弃。屏幕反光、刷新、亮度的影响都不知道。
- **VPN**：所有者的手机开着 v2rayNG。「连上了没回应」是拿不回数据的本地监听模拟的；接口名判断 VPN 只在模拟器上跑过（没有 VPN 时返回 false）。真开 VPN 时是报得对还是能连上，都不知道。
- **AP 隔离**：没有环境。
- **API 34+ 的接口枚举**：`NetworkInterface.list` 只在 API 30 上跑过。所有者手机上如果拿不到地址，页面会报「没连局域网」。

包的大小：30,232,321 → 30,569,233 字节，多 336,912 字节（0.32 MiB），其中 `classes.dex` 多 205,748 字节（zxing 和新的原生通道），`libapp.so` 多 196,608 字节（压缩前）。基准是 R62 之前的包，所以这是 R62、R65、R46、R66、R45 加起来的。

## 取舍

- `mobile_scanner` 不用：它在 Android 上靠 ML Kit（闭源）。选 zxing-android-embedded 4.3.0，Apache-2.0。它 2021 年之后没发版，扫码页用的是老的 Camera1 接口，真机上有问题先怀疑这里。
- 二维码只收私有 IPv4，IPv6 局域网不支持：家用 Wi-Fi 和手机热点都有 IPv4。
- 没做手动输入配对码：相机坏了就用加密备份文件。
