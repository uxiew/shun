## 已做的代码改动

- 冷启动不再请求上游 GitHub 检查更新；AI、云同步、更新检查默认关闭（R01）。模拟器上按 UID 看内核流量：fork 冷启动→设置→后台→deep link 全程 0 条，原版冷启动即有（BAS02）。
- 选了代理就必须经代理，配置无效或代理失败一律报错，不静默直连（R03）；终端输出不再因切包乱码；断线恢复不重跑启动命令。
- 连接前一次算好不可变的路线（R05）：矛盾、循环、超 3 跳、非法地址端口都在拨号前拒绝；保险库格式不变，仍能和桌面端同步。
- SOCKS5 加固（R06）：配了口令不降级为无认证、回复严格校验、失败码逐个说清、取消即关、各阶段有期限。顺带绕过 dartssh2 2.22.5"SSH 版本行被拆包就断开"的缺陷。
- 代理入口 + 跳板（R07）：目标上同时配代理和跳板时，代理只用于连第一跳；每一跳失败都报出哪台机器、哪一步；服务器指纹变了一律阻断（只能删除旧指纹后重连重新核对）。
- 连接代次与资源所有权（R08）：每个标签一次只有一个有效的连接尝试，取消、关标签、应用退出都会让它失效，迟到的结果一律关掉；断线、失败、取消都把已建好的连接连同跳板释放干净。真实 OpenSSH 上 100 轮（另跑 500 轮）连接/取消/恢复/关闭/销毁，fd 和服务器侧连接都不增长。连接回写不再冲掉用户中途的编辑、不再复活已删主机。取消后不再误弹「已连接」。
- 凭据与入口统一（R09）：终端、SFTP、监控、系统管理、端口转发经代理/跳板/直连都只用这一条已验证连接（真实 OpenSSH 验证）；私钥在拨号前解析并自签自验（能识别密文被改）；keyboard-interactive 不再把密码填给验证码之类的提问；信任按主机名规范写法比对；主机对象的调试输出和导出不再含明文凭据；凭据解不开时不再拖垮整个保险库；连接瞬间失败不再让 App 被系统杀掉（上游就有）；SFTP 握手 10 秒期限；备份和换机迁移排除全部数据。
- 连接路径编辑器与最小 SSH 闭环（R10）：编辑器里直连 / 经代理 / 经跳板机三选一，「先经代理再走跳板」是显式高级开关；实时显示连接时会怎么走，矛盾配置不让保存；「测试连接」按未保存的配置核对指纹、登录，只检查远端 PTY（`/dev/pts/N`），不开 shell、不执行启动命令；失败页显示实际路线和下一步。模拟器上全程用界面走通了新建主机、经 SOCKS 代理、导入私钥、密码填错、正式连接敲 `tty`。顺带修了上游「选一次跳板机就红屏」。
- 只读 Tailscale 目录的 HTTP 适配（R11，还没有界面）：只发换 token 和列设备两种请求，只要 `devices:core:read`，不跟随任何重定向，401 只受控刷新一次，429/403 不重试。粘贴的 token 读完即丢、一律「范围未验证」；自己的 OAuth client 只在你要求且服务器确认只读时才存，存在和保险库分开的加密文件里。没有 Tailscale 账号，全部用本机假 API 验证（模拟器上也跑过，私有目录和日志里搜不到任何凭据）。
- 目录缓存（R12，还没有界面）：每个来源的设备记录存本机，刷新只加、只改、只标「不见了」，从不删；不完整、空列表、出错都不动已有记录。导入的主机只有地址会跟着目录变，而且只在你没改过地址时；用户名、端口、路由、指纹信任一概不碰。两个来源即使都写 `-` 也不合并。
- Android 独立插件（X02）：「设置 → 插件（实验）」列出声明了本 App 插件接口的 App，批准前不启动它们；批准时核对证书。插件和宿主在每次 Binder 调用里互相核对对方的 UID 和证书——模拟器上实测：流氓 App 拿到 Binder 也调不动插件，拿到转交来的宿主回调也调不进宿主；同包名换签、冒用内置 ID、调试证书签的插件进 release 宿主都被拒。echo 只是测试插件，不是 Mosh。
- 插件契约 v1 落成 `packages/plugin_api`（X00）。
- 主 App 接入轻量插件注册表（X01）：内置 SSH/路由构造时即可用，不等任何插件发现；外部包冒用内置 ID、自称内置、同 ID 抢位都被拒；停用/撤销/换签/卸载只关该插件自己的会话。顺带补了契约漏洞：单独安装的包自称 `bundled` 原先能跳过用户批准和证书核验。设备关联还没持久化（X05 一起做）。

## 要知道的行为变化

- 跳板机自己配的代理不再被隐式套用，会报错；需要"先经代理再走跳板"时，把代理设在**目标主机**上。
- 服务器指纹变了不再能一点"确认更新"就连上；要在弹窗里删除旧指纹，重连时重新核对。
- 断线自动恢复沿用这个标签原来的路线和账号；期间改了主机、跳板或代理，要关掉标签重新连才生效（R08）。
- 断线（含 shell 里 `exit`）后这个标签的 SSH 连接连同跳板立即释放，借它开的端口转发随之不可用，条目要手动停（自动撤掉属 R24）。
- 导出的保险库不再含密码、私钥和代理口令（上游是明文全量导出）；同一台手机再导入会沿用本机凭据，但只在地址、端口、用户名都没变时（R09）。
- 跨服务器复制/移动先问走手机中转还是服务器直传；以前会自动先试直传（R09）。
